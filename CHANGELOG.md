# История изменений

Все существенные изменения проекта документируются в этом файле. Версии оформляются по правилам Semantic Versioning.

## [2.0.0] - 2026-09-14

### Добавлено

- Содержательные отчёты и презентации для лабораторных работ 1–11 в формате QMD.
- Исходные задания, иллюстрации и ресурсы шаблона Quarto для каждой работы.
- Сборка отчётов в PDF и DOCX, презентаций в PDF и HTML.
- Единое соглашение об именовании файлов по схеме `nettech-labNN-{report|presentation}`.
- Репозитории и релизы на GitHub, GitVerse и SourceCraft.

### Исправлено

- Метаданные курса, автора и репозитория.
- Правила Git для хранения всех производных форматов Quarto.
- Стабильная сборка PDF в Windows через XeLaTeX без автоматического обновления пакетов.
