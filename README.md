## Структура

- `labs/labNN/report` - исходник отчёта в формате QMD, ресурсы, изображения и результаты сборки PDF и DOCX;
- `labs/labNN/presentation` - исходник презентации в формате QMD, ресурсы, изображения и результаты сборки PDF и HTML;
- `labs/labNN/task` - исходное задание на лабораторную работу.

## Сборка

В каталоге `report` или `presentation` выполняется:

```sh
make
```

Либо напрямую:

```sh
quarto render
```

Все производные файлы сохраняются в каталоге `_output` соответствующего отчёта или презентации.
