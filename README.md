## Структура

- `labs/labNN/report` - исходник отчёта, ресурсы, изображения и собранный PDF;
- `labs/labNN/presentation` - исходник презентации, ресурсы, изображения и собранный PDF;
- `labs/labNN/task` - исходное задание на лабораторную работу.

## Сборка

В каталоге `report` или `presentation` выполняется:

```sh
make
```

Либо напрямую:

```sh
quarto render
```
